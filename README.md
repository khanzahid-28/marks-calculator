# Marks Calculator

A beginner Python project that takes marks of 3 subjects and calculates the total, percentage and grade.

## How it works
1. The program asks for marks of 3 subjects.
2. It adds them to find the total.
3. It divides the total by 3 to find the percentage.
4. It prints a grade using if / elif / else.

## Grading
- 75% or more: A
- 60% or more: B
- 40% or more: C
- Below 40%: Fail

## How to run
Run `marks_calculator.py` with Python 3 and enter the marks when asked.
